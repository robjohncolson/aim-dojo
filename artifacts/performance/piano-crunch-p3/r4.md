# R4: skip unused piano reverb

Implemented the updated R4 decision: piano skips reverb construction and scheduling, and accepts a different opening random sequence. No replacement draws or discarded IR are generated. The legacy `?piano=0` arm retains the real reverb and its original position before Tone/NoiseSynth construction.

The runtime delta is 5 added / 2 removed lines: an `!PIANO` guard around the existing reverb work in `initAudio`, the required sequence comment, and an `!PIANO` guard around `exitRunning`'s scheduler call. These are the two external entries into the scheduler/builder. Piano cannot bootstrap a queued callback. The three IR helpers themselves are unchanged. Reversing only these guards and the comment restores the entire runtime from `445af12` byte for byte, preserving R1-R3, the earlier bloom, walls, and authored voice caps.

## Random sequence decision

`makeIR` used shared `Math.random` before the opening combo and optional prototype wind. `rnd()` uses that same generator; there is no daily gameplay seed. Skipping the IR intentionally changes downstream random picks. Their validity is preserved, not their former bytes.

| Sample rate | Removed IR draws per cold piano initialization |
| ---: | ---: |
| 44,100 Hz | 194,040 |
| 48,000 Hz | 211,200 |
| 96,000 Hz | 422,400 |

The unchanged order on legacy is listener creation, IR, Tone/NoiseSynth construction, then run reset and combo/wind selection. Other shared consumers include decorative stars/grid colors, THREE UUIDs, target placement and motion. Their possible sequence shift is accepted on piano. No constructors, random consumers, or clock settings were moved in R4. The earlier draw-discard prototype is historical evidence only; its helper was removed from the tests and no such loop exists in this change.
